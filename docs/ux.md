# The Today workspace

Today opens on tasks planned for today or earlier and any due or overdue deadline. An unscheduled task stays available in All tasks and its project. New captures in Today show their plan date before saving. Upcoming groups future plans by date. Moving several tasks changes their plan together and keeps each deadline visible.

On desktop the project sidebar and task rows scroll independently. Today has a compact date heading, a persistent composer and one reading column. On phones the list occupies the full width and navigation stays reachable near the bottom. Task titles open the editor in place. Search, projects, Done, Trash and Settings remain accessible in both layouts.

Completing a task updates the list after a successful save. Undo and reopening from Done support recovery. A failed edit retains its draft. A concurrent change pauses saving and gives the owner a choice to copy the draft or discard and reload. The interface supports keyboard navigation, reduced motion, larger text and dark mode.
